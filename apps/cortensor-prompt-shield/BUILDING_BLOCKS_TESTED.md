# Building Blocks Tested (`openminion==0.1.24`)

This matrix documents every OpenMinion `0.1.24` Python SDK & CLI building block exercised by **`cortensor-prompt-shield`**, verified on macOS (`arm64`, Python 3.15 / 3.11+ compatible) against live OpenAI-compatible inference and local `pytest` suites.

| # | Building Block | Surface Used | Status | What Worked | What Broke / Friction Observed |
| :-: | :--- | :--- | :---: | :--- | :--- |
| 1 | **`Agent` Lifecycle & `config_path`** | `with Agent(config_path=..., agent_id=...)` | **Pass (with workaround)** | Clean context-manager startup/teardown; isolated SQLite storage per workspace. | Default SDK turn sends **43,301 bytes** (`16,695` chars system prompt + 8 built-in tools) even for a 2-character `"hi"` prompt, breaking strict/edge endpoints (8 KB cap). Solved via our `CompactGuardProxy` middleware. |
| 2 | **Custom `@tool` & Scopes** | `@tool(min_scope="READ_ONLY", idempotent=True)` & `forced_tools=[...]` | **Pass** | Decorator metadata cleanly registers Python functions and forces deterministic first-turn tool calls (`scan_agent_tools`, `inspect_openminion_policy`). | Unannotated `@tool` functions default cleanly without warning, motivating our static AST scanner (`OM-SCOPE-001` / `OM-SCOPE-002`). |
| 3 | **Dangerous Tool Approval Gate** | `@tool(min_scope="WRITE_SAFE", dangerous=True)` + `approval_callback` | **Pass** | Clean programmatic interception via `approval_callback(tool_name, args, approval_id) -> bool`; verified both `DENY` (fail-closed, zero files written) and `ALLOW` paths. | Requires `action_policy.default_action = "require_confirm"` in `agents.json`; easy to misconfigure if a custom `agents.json` omits `action_policy`. |
| 4 | **Streaming Progress (`run_stream`)** | `agent.run_stream(prompt, on_delta=...)` | **Pass** | Emits real-time structured progress/delta events during tool execution and final synthesis. | Event payloads mix dict shapes across lifecycle stages; typed event dataclasses/TypedDicts in the public export would improve DX. |
| 5 | **Bounded `subagent()` Delegation** | `subagent(parent, name="target-sandbox", tools=..., timeout_seconds=60)` | **Pass** | Inherits parent runtime/config cleanly while isolating instructions and tool lists for sandboxed adversarial probing (`VEC-01`..`VEC-03`). | Inherits the same 16.7 KB runtime grounding prompt overhead as the parent agent, doubling token cost on multi-agent loops. |
| 6 | **Pydantic Structured Output** | `Agent(..., output_type=SecurityAuditReport)` + `AgentOutputValidationError` | **Pass** | Validates model output directly into Pydantic v2 models (`result.output`); raises typed `AgentOutputValidationError` on schema drift. | Works cleanly with OpenAI-compatible JSON models; adding an automatic schema-repair retry flag on `Agent` would reduce caller boilerplate. |
| 7 | **Shared vs. Isolated `session_id`** | `agent.run(..., session_id=...)` | **Pass** | Durable SQLite session memory recalls markers across turns in `shield-session-alpha` while isolating `shield-session-beta` with zero cross-session canary leakage. | Clear, reliable security boundary when `memory_enabled` is scoped appropriately. |
| 8 | **Provider Switching & Config** | `agents.json` (`openai`, `cortensor`, `openrouter`, `echo`) | **Partial** | Switching between `openai` (custom `base_url`) and `cortensor` (`/api/v2/completions`) works cleanly via `agents.json`. | `openminion setup --list-providers` lists **20** providers (`cortensor-portal`, `custom-openai-compatible`, etc.), while `openminion config init --provider` only accepts **9** choices. |
| 9 | **Error Taxonomy & Diagnostics** | `ProviderError`, `TurnTimeoutError`, `openminion setup --list-providers --json` | **Partial** | `ProviderError` preserves HTTP status & upstream error body cleanly. | Two config-loader bugs found: omitting `default_channel` raises hard `RuntimeError` even in `mode=warn`, and passing an int to `context.identity_budget` reports the wrong field name (`context.budget`). |
